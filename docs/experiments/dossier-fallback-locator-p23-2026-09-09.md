# 回退定位器对比（grid vs coverage-gaps 窗口）——P23 实验记录

> 2026-09-09（实验分支 feature/kp-dossier-workflow，P23）。
> 承接 P21（原文回退原型：复合 3.19→3.54，瓶颈=大剧本 located 词面定位 1/4 漏段落）
> 与 P22（coverage gaps：gap spans + 场景多窗锚点，本地零成本）。
> 本实验回答 P23 gate：**用 P22 的锚点/缺口窗口替换固定网格定位，located 反降是否消除？**

## 方法

- 重放 P21 的 21 个 located 触发问（大剧本 >22k 字符：古城秘史/奈落/巫/模组集/火焰/猫是我），
  只换定位器，其余（原文子代理 prompt、judge 口径、20k 预算、top12 窗口）不变：
  - **grid**（P21 基线）：固定 6000 字滑窗（400 重叠），问题 CJK 二元组打分；
  - **gaps**（P23）：候选窗 = 场景锚点后 2500 字（含前 300 衔接语）+ 未覆盖 gap 区间（大 gap 按 2000 字切块），
    同样按问题二元组打分取 top12 → 原文序拼装 ≤20k。
- scenes/gaps 来自 dossier-cache 的 P20 档案（与 P21 同批）。
- 驱动：`ab-fallback.mjs --input=<P21 json> --locator=gaps`（逐问记录 prevFallback=grid 分可配对）。

## 结果

配对（同一问两定位器都出 judge）n=16：**基线 2.63 → grid 3.50 → gaps 3.50（平手）**
（成功 judge 17/21——上游 503 flake 吃掉 4 条：翡翠神/驱逐解法/猫是我×2，均与定位器无关）

逐问差异（gaps vs grid：↑4 ↓3 =9）：

| 变化 | 问 | 说明 |
|---|---|---|
| ↑2 | 模组集 朱莉密室（grid 1 → gaps 3） | **P21 反降案例修复**：石桌/陈设段被锚点窗纳入 |
| ↑2 | 巫 荒地土壤（grid 1 → gaps 3） | **P21 反降案例修复** |
| ↑2 | 奈落 工具间（3→5）、巫 竹田学渊源（3→5） | 内容更全 |
| ↓4 | 古城秘史 委托人（5→1/fab）、巫 荒地样貌（3→1/fab） | grid 已 5/3 的问被 gaps 窗排布带偏（答非所问/fab）——更像回答随机性与 judge 噪声 |
| ↓2 | 火焰 魏乙鸣（5→3） | judge 首次空响应重试后仍降（噪声） |
| =9 | 其余 | 含王博（两定位器均 1/fab，Good End 条件段仍未定位到） |

## 结论（P23 gate 判定：部分通过）

1. **定位器升级统计平手**（3.50 = 3.50）：P21 的 4 例反降修复了 2 例（朱莉密室/荒地土壤），
   但 grid 高分问上也出现等量新下降——±2 的生成/judge 噪声完全盖过定位器差异。
2. **"问→20k 窗口"这个离线模拟形态本身有上限**：问题与答案段落的词面关联弱时（Good End 条件、
   委托人开场段），两种定位器都会漏——问题不在窗口对齐，而在**没有场景先验**。
   运行时真实形态是 **KP 带着场景名/当前场景来查证** → 直接取该场景锚点窗（≤几 k 字），
   而不是盲扫 20k——那才是 P22 锚点的主场，本离线重放模拟不了。
3. 回退本身的收益在 located 子集依旧显著（基线 2.63 → 3.50，Δ+0.87；P21 全 located 口径
   2.50→3.20 同向）——**无论定位器，原文回退在档案答不出的问上价值稳定**。

## 遗留

- 王博 Good End 类"条件在场景外/结局段"的问：回退仍失败——其答案常驻 endings 层/原文后段，
  两定位器都够不着；运行时若把 endings/真相原文段落也纳入锚定窗可解。
- 上游 503 偶发（非本实验问题）；重放成本 ~21×2 调用。
